人工样本另外核对热门书次数、分类占比、读者次数分布及分类偏好。清洗和统计的 CLI 入口分别做了运行检查。测试环境为 Python 3.12.14、openpyxl 3.1.5，分别使用 pandas 2.2.3、3.0.1、3.1.0 运行全部 14 项测试，均无警告或错误。

## PR #2 审核修复

修复前在 pandas 3.1.0 复现了空输入的 `int('')` 错误，以及财产号没有唯一 ISBN 关联时的 `Pandas4Warning`。无效 ISBN 改用 Python 计数，避免空字符串 Series 的求和行为差异；关联结果先转为 object，再填充空字符串。保留现有依赖范围，兼容 pandas 2.x 和 3.x。

修复后在 pandas 3.1.0 下，以警告按错误处理的方式重新运行 36,908 条模拟记录的生成、清洗、统计 CLI。结果与上方全量模拟测试一致：36,841 条接受、67 条待核查、279 条无效 ISBN、358 位模拟读者、200 个图书主键。分类占比、读者分布和看板不含读者标识的检查全部通过。
