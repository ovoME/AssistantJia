# 「小嘉」安全与权限检查清单（D：步骤8 安全检查）

> 上线前逐项核验，全部通过方可宣布完成。对应方案「数据安全合规问题」风险项。
> 接口契约见 `docs/api-contract.md`；部署见 `docs/部署手册.md`。

## 一、认证与权限

- [ ] **管理端鉴权**：`/api/admin/*` 全部校验管理令牌（建议 `X-Admin-Token`，对应 `.env` 新增 `ADMIN_TOKEN`），未带/错误返回 401
- [ ] **读者端会话**：`session_id` 不可枚举、可过期；会话数据绑定读者
- [ ] **权限分级**：读者端不能触达 `/api/admin/*`（Nginx 层对 `/api/admin/` 单独鉴权）
- [ ] **默认密钥更换**：所有密钥使用随机长串，禁止示例值

## 二、输入与注入防护

- [ ] 接口参数经 Pydantic 校验，畸形输入返回 400
- [ ] 对话输入长度限制（≤2000 字符）与基础内容过滤
- [ ] OPAC/检索参数参数化，防注入与越权查询
- [ ] 前端渲染转义，防 XSS（对话回复按纯文本渲染）
- [ ] 知识库上传限制文件类型与大小

## 三、敏感信息与数据安全

- [ ] `.env` 不入库（.gitignore 已忽略），服务器 `chmod 600`
- [ ] API Key / 密码 / 证件号严禁贴给 AI（用占位符）
- [ ] 日志脱敏：证件号打码；错误堆栈不回显给用户
- [ ] 借阅数据本地化：仅存本馆服务器，不传出境外
- [ ] 定期备份：Chroma 卷 + Redis（见部署手册第五节）
- [ ] 管理端响应不含证件号等原始敏感字段

## 四、访问控制与限流

- [ ] Redis 限流：单 IP/单会话调用频率限制（防刷 API、防成本失控）
- [ ] 大模型调用频率限制与月度预算控制
- [ ] 防火墙仅放行 80/443/SSH；8000/6379/8001 不对公网
- [ ] CORS 白名单：仅允许前端域名（当前 A 的 main.py 为 `allow_origins=["*"]`，上线前必须收紧）

## 五、传输与基础设施

- [ ] 生产启用 HTTPS（Caddy/certbot 自动续期）
- [ ] 容器非 root 运行（Dockerfile 可追加 USER 指令）
- [ ] 镜像漏洞扫描（CI 加 trivy）与依赖更新（开启 Dependabot）
- [ ] 续借/预约等写操作日志留痕

## 六、验收口径

- [ ] 用脚本/手工逐项核验，记录通过/失败项
- [ ] 输出安全验收结论：全部通过 / 存在失败项（附修复计划）
